# 空天智能课程实验

本仓库汇总第一小组的知识图谱、目标检测、语义分割与强化学习四项课程实验代码。研究数据、训练权重、学生信息、课程报告与机器凭据未包含在公开仓库中。

| 实验 | 内容 | 示例结果及口径 |
| --- | --- | --- |
| 知识图谱 | 三元组处理、TransE/TransH 对照、交互查询 | 同一划分 filtered MRR：0.0261 → 0.0658 |
| 目标检测 | YOLOv5 微小目标检测及网络、损失探索 | 同一课程验证集 mAP@0.5：91.2616% → 94.2207% |
| 语义分割 | UAVid 原分辨率评估、预训练模型融合、错误分析 | 第八轮验证集 mIoU 0.73852；已暴露测试集描述性 mIoU 0.72814 |
| 强化学习 | 仓库机器人导航、DDPG/TD3 及战场环境 | 两个 DDPG 种子在共同 100 场景分别成功 98 和 97 次 |

这些指标对应不同任务和评价集合，不能相互比较。语义分割验证和测试数据被先前多轮开发查看过，不能视为完全独立的盲测；外部 AeroScapes 单折专家未通过晋级条件，未进入最终模型。
