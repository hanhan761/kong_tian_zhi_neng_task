# 目标检测

本目录包含课程 YOLOv5 工程源码及相关实验代码。最终方案使用 YOLOv5l、COCO 预训练和相应训练配方；注意力、P2、NWD 与 ECA 为探索分支，不声称均属于最终模型。

请按原工程的 GPL-3.0 许可使用，安装 requirements.txt，另行配置数据路径和预训练权重。课程图像、个人设备日志、实验权重和原始数据均未公开。scripts 中部分历史脚本依赖原实验的配置与结果目录；缺少相应输入时需要自行适配，不能直接复现报告数字。

自制数据公开页：https://www.kaggle.com/datasets/martinqu/spacecraft-separation-detection-1000
