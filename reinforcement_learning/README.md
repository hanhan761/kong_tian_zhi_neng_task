# 强化学习

本目录包含连续控制智能体、仓库和战场环境、采集器、回放池、训练评价入口及配置。原实验以 Python 3.11 和 requirements_runtime_lock_cpu.txt 记录的环境运行。

训练入口为 run_experiment.py，评价入口为 evaluate.py；configs/ 提供原实验配置示例。训练输出路径与 seed 请按实际环境调整。已训练权重、视频和训练数据未包含，因此必须重新训练或自行提供获准使用的模型。

相同 100 个场景中，两个基础 DDPG 训练种子的末次模型分别成功 98 和 97 次；TD3、探索参数和战场奖励对照未证明跨种子的稳定优势。
